# VidyaMitra Project Rules

## Documentation Location
- All project documentation (reports, plans, walkthroughs, guides, verification results, etc.) MUST be placed in the `docs/` folder at the project root (`VidyaMitra_AI_EdTech/docs/`).
- Never place documentation files at the project root or in other directories.
- When generating new documentation, always write it directly to `docs/`.
- When updating documentation, update the files in `docs/`.
- If a new doc file is created, also update the documentation table in `README.md` to include a link to it.
